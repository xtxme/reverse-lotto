# สถานะการตรวจ Phase F — 13 พฤศจิกายน 2026

โค้ดที่เผยแพร่เป็น snapshot ของงาน OpenCode ไม่ใช่การประกาศว่าพร้อมยืนยันผลพยากรณ์ล่วงหน้า
รายงานเดิมคงไว้ตามต้นฉบับ ข้อจำกัดเพิ่มเติมจากการตรวจ source และทดลอง offline มีดังนี้

1. `pfledger.freeze()` ตรวจเวลาตอนเริ่ม แต่ไม่ตรวจซ้ำหลังคำนวณก่อนบันทึก จำลองการคำนวณข้ามเวลาปิดแล้วพบว่ายังรับ forecast
2. Audit ตรวจเวลาเริ่ม snapshot; snapshot ว่างที่เสร็จหลังปิดยังผ่าน audit ได้ และ ledger ไม่บังคับว่า snapshot ต้องเสร็จก่อนเวลา forecast
3. Headroom ถูกตรวจตอนเริ่ม capture ไม่ได้ตรวจซ้ำในทุก iteration ของ `read_pages()` ขณะที่ Phase D ยังบังคับเพดานรวมอยู่
4. การเก็บ snapshot คีย์วัน/รอบ/horizon เดิมใช้ upsert และลบ page/row เดิม จึงยังไม่ใช่หลักฐาน snapshot แบบ append-only
5. `generated_monotonic_ns` ใน ledger คำนวณจาก Unix timestamp ไม่ใช่ monotonic clock จริง
6. การเลือกข้อมูลฝึกใช้วัน/รอบก่อนหน้า แต่ยังไม่บังคับเวลาที่ข้อมูลนั้นเก็บมาพร้อมใช้งานจริง ณ cutoff
7. Proper scores ในผล baseline เป็นเป้าหมาย residue ห้าหลัก ควรเพิ่ม log loss/Brier แยกเป้าหมายล่างและบน

ชุดทดสอบเดิม 35 ข้อผ่าน ไม่ได้ครอบคลุมข้อค้นพบทั้งหมดข้างต้น
การตรวจนี้ไม่ได้แก้โค้ดบริการหรือเปิด scheduler และไม่ใช่การตรวจความปลอดภัยครบทุกส่วน
