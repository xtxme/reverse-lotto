# งาน A — วิจัย THLotto ยี่กี

โฟลเดอร์นี้รวบรวม **งาน A ทุก Phase** ของการศึกษาระบบยี่กี THLotto ทั้ง Phase A, Phase B และ Phase C รวมข้อมูล หลักฐาน ภาพ สคริปต์ และบันทึกตรวจอิสระ

คำว่า **งาน A** คือชื่อชุดงานทั้งหมด ส่วน **Phase A / B / C** คือระยะย่อยภายในงาน A

## ลำดับการอ่าน

1. [Phase A — รายงานเริ่มต้น](PHASE_A_REPORT.md): สถาปัตยกรรม รอบเวลา การส่งเลข สูตรคำนวณ และข้อจำกัดเดิม
2. [Phase B — สารบัญ](phase_b/README.md) และ [รายงานฉบับเต็ม](phase_b/PHASE_B_FINAL_REPORT.md): ตรวจเวลา เลขซ้ำ Polling และ Monte Carlo
3. [Phase C — สารบัญ](phase_c/README.md) และ [รายงานฉบับเต็ม](phase_c/PHASE_C_FINAL_REPORT.md): ประวัติย้อนหลัง อัตลักษณ์แสดงผล และลำดับรายการ
4. [บันทึกตรวจอิสระภาษาไทย](phase_c/INDEPENDENT_REVIEW_TH.md): ข้อแก้ไขและข้อจำกัดที่ต้องอ่านควบคู่กับรายงานเดิม รวมถึงข้อสังเกตต่อ Phase A/B

## โครงสร้าง

```text
งาน A/
├── README.md                 # สารบัญงาน A ทุก Phase
├── PHASE_A_REPORT.md         # README เดิมของ Phase A เก็บเนื้อหาเดิม
├── *.md                      # รายงานรายละเอียด Phase A
├── evidence/                 # หลักฐาน ข้อมูล และสคริปต์ Phase A
├── phase_b/                  # Phase B ทั้งชุด
└── phase_c/                  # Phase C ทั้งชุด และบันทึกตรวจอิสระ
```

## หมายเหตุการใช้งาน

- รายงานและข้อมูลเดิมคงเนื้อหาตามต้นฉบับ การจัดครั้งนี้เป็นการย้ายโครงสร้าง repository
- เส้นทาง `/Users/icy/research/` หรือ `research/` ในเอกสารเดิมเป็นบริบทตอนเก็บข้อมูล เมื่อนำมาใช้จาก repository นี้ ให้เริ่มจากโฟลเดอร์ `งาน A`
- ตัวอย่างเรียกตัวตรวจสูตร Phase A จากราก repository:

```bash
cd "งาน A/evidence/reproducible_tests"
python3 verify_formula.py
```

- สำหรับ Phase B/C ให้อ่านคำสั่งในสารบัญของแต่ละ Phase โดยเข้าโฟลเดอร์นั้นภายใต้ `งาน A` ก่อน
- อ่านบันทึกตรวจอิสระร่วมด้วย: รายงานเดิมบางข้อมีการแก้ไขความหมายหรือค่าสถิติภายหลัง
