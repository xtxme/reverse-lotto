4. บน–ล่างเกือบ independent
5. ตารางเลขนิ่งมี human digit preference

- สูตร deterministic ไม่ได้แปลว่า predict ได้; มันแปลว่า “ถ้ารู้ input ทั้งหมด ก็คำนวณได้” — แต่ input ยังไม่เกิด
- LINE result posts เกิดที่ close+2 นาที ตรงกับ shoot close; เป็นการ **รายงานผล** ไม่ใช่คำทำนาย
- ตารางเลขนิ่งรายชั่วโมงไม่มีความสัมพันธ์กับ pool; เป็น fixed daily sequence

> **ข้อห้าม:** อย่าสมมติว่าเข้าถึง backend หรือข้อมูลลับได้; การวิเคราะห์นี้ใช้เฉพาะข้อมูล public/authorized

## 8. วิธีทดสอบล่วงหน้าจริง (Prospective Test)

ถ้าต้องการพิสูจน์ข้ออ้างอย่างถูกต้อง:

1. **Pre-register** ก่อนเก็บ data:
   - primary outcome (top / bottom / either)
   - นิยาม trigger/target
   - จำนวนวันขั้นต่ำ
   - วิธีแก้ multiple testing
   - เกณฑ์ success (log loss/Brier/CI)
2. **เก็บข้อมูลใหม่** หลังล็อก:
   - บันทึก timestamp ของคำทำนายก่อนเริ่มชั่วโมง
   - บันทึก screenshot/ข้อความต้นฉบับ
   - เก็บผลจากเว็บ/แหล่งอ้างอิง
   - ห้ามแก้ย้อนหลัง
3. **Hold-out** แบบ chronological:
   - Train/validation สำหรับพัฒนา
   - Test เปิดครั้งเดียว
4. **Power analysis:**
   - effect ที่สนใจ (เช่น +2 pp) ต้องใช้ n เท่าไร
   - อย่าใช้ 86 วันแล้วสรุป
5. **Multiple testing:**
   - นับทุก metric/model ที่ทดสอบ
   - ใช้ BH/Holm หรือ hierarchical testing
6. **รายงานทั้งหมด:**
   - ทั้ง success และ failure
   - effect size + CI
   - ไม่เลือกเฉพาะช่วงที่ดี
7. **Independent replication:**
   - คนละ analyst, คนละ dataset
   - ถ้า replicate ไม่ได้ → ถือว่าไม่จริง

**ตัวอย่างการออกแบบ:**

- เก็บ 60 วัน (≈5,000 รอบ)
- Primary: top-digit hit rate ต่อชั่วโมง
- Baseline: empirical conditional baseline
- Test: permutation within day + day bootstrap
- Success: one-sided p<0.05 หลัง Holm across 3 outcomes, และ effect ≥2 pp ในช่วง test
- ถ้าไม่ผ่าน → สรุปว่าไม่มีหลักฐาน

## 11. คำตอบสุดท้ายต่อคำถามหลัก

### 11.1 สูตรในภาพมีข้อไหนแม่นกว่าสุ่มจริงหรือไม่?

**ไม่มี** ภายใต้การตีความที่กำหนดไว้ล่วงหน้าและหลังแก้ multiple testing
- 17 ข้อ: p ≥ 0.193 ทุกข้อ; q ≥ 0.974
- รูป 1: 6.71% vs 7.0%
- รูป 2: 6.67–8.97% vs 9.0%
- 69→65: 1 ครั้ง; insufficient

### 11.2 คนให้เลขรายชั่วโมงมีหลักฐานความแม่นยำมากกว่าสุ่มหรือไม่?

**ไม่เพียงพอ**
- ล่าง: null (56.57% vs 56.81%)
- บน: +2.39 pp, p≈0.019; หลังแก้ 3 outcomes p≈0.059; ไม่เสถียร; max-hour p=0.089
- เป็นตารางเดียวที่ถูกลอก; effective n=86 วัน
- ตารางมี human digit preference ไม่ได้ derive จากผล

### 11.3 พบ Pattern แบบใดที่ตรวจซ้ำได้?

ไม่มี pattern predictive ที่ตรวจซ้ำได้
สิ่งที่ตรวจซ้ำได้เป็นเพียง descriptive:
- distribution ใกล้ uniform
- ไม่มี autocorrelation lag 1–4
- ไม่มี state clustering
- บน–ล่างเกือบ independent

### 11.4 Pattern ไหนเป็นเพียงความบังเอิญ?

5 ตัวที่ nominal p<0.05 (หรือใกล้):
- after 69 distribution (p=0.014, q=0.805)
- bottom units lag3 (p=0.035, q=0.805)
- top hundreds = bottom tens (p=0.039, q=0.805)
- top tens lag1 (p=0.048, q=0.805)
- after double distribution (p=0.053, q=0.805)

### 11.5 มีข้อสรุปใดที่ข้อมูลยังไม่เพียงพอ?

- เจตนา/ความรู้ล่วงหน้าของผู้ให้เลข
- การใช้สูตรในภาพจริง
- predictive skill ในอนาคต
- expected value / arbitrage
- กลไกหลังบ้าน/non-public data
