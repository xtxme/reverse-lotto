# งาน B — ตรวจสูตรเลขในภาพ และผลยี่กีจากไฟล์ LINE

## ข้อมูลที่ตรวจ

- Input: ไฟล์ LINE `...สมาคมคนรวย(10).txt` และรูปภาพ 3 รูปที่ผู้ใช้แนบ
- ช่วงผล: 2026-08-13 ถึง 2026-11-07 (วันที่ของผลรางวัล; เวลา Asia/Bangkok)
- บรรทัดข้อความ LINE: 233,724; ผลจับยี่กีไม่ซ้ำ: 7,469 รอบ; วันเล่นหวย: 87 วัน
- วันเล่นหวยที่ผลครบ 88 รอบ: 61 วัน; อีก 16 วันมี ≥87 รอบ
- ผลที่มีรอบต่อกันห่าง 15 นาทีแน่นอน: 7,352 คู่
- ตารางเลขนิ่งที่พบในแชต: 886 ข้อความ; ตารางเลขเดี่ยวรายชั่วโมงที่โพสต์ก่อนเริ่มชั่วโมงและมีผลครบ 4 รอบ: 1,545 ชั่วโมง
- ผลจากแชตมีการส่งซ้ำทุก 15 นาที แต่ในชุดที่อ่านไม่พบข้อขัดแย้งเมื่อรวมตามรอบ/วันที่ (ไม่เท่ากับยืนยันกับเว็บต้นฉบับครบทุกแถว)

## นิยามการทดสอบรูปภาพ (ต้องให้ผู้โพสต์ยืนยันก่อนถือเป็นสูตรจริง)

- `เบิ้ล` สมมติเป็นล่างสองหลักเดียวกัน (00,11,...99)
- `หลัง ...` สมมติเป็นผลล่างของรอบถัดไปทันที 15 นาที ไม่ใช่ภายใน 4 รอบ
- `69–65` ทดสอบหลังล่างเป็น 69 หรือ 65 โดยไม่ถือว่า 69→65 ที่ต่อเนื่องเป็นเงื่อนไขเดียวกัน
- `เลขในชุด` ต้องตรงเลขสองหลักล่างทั้งชุด เช่น 85 ไม่ใช่มี 8 หรือ 5 ปรากฏตัวใดก็ได้
- กติกาในรูปไม่มีเวลาต้นฉบับและไม่ได้ระบุช่วงตาม: ผลจึงเป็นเพียงการทดสอบ “สมมติฐานตีความ” ไม่ใช่การวัดความแม่นยำของเจ้าของรูป

## ผลทดสอบรูปแรกและรูปสอง

| เงื่อนไขที่นิยามล่วงหน้าในการตรวจครั้งนี้ | ผลจริง | อัตรา | ฐานสุ่มใน 1 รอบ |
|---|---:|---:|---:|
| ล่างเบิ้ล แล้วล่างรอบถัดไปอยู่ใน {85,97,94,95,74,96,75} | 49/730 | 6.71% | 7% |
| ล่าง 69 หรือ 65 แล้วล่างรอบถัดไปอยู่ใน {56,58,59,68,69,76,78,79,89} | 12/153 | 7.84% | 9% |
| ล่าง 69 เท่านั้น แล้วรอบถัดไปอยู่ในชุดเลขเก้าตัว | 5/75 | 6.67% | 9% |
| ล่าง 65 เท่านั้น แล้วรอบถัดไปอยู่ในชุดเลขเก้าตัว | 7/78 | 8.97% | 9% |

การเกิด 69 แล้ว 65 ใน 2 รอบติดต่อกัน พบเพียง 1 ครั้งในคู่ที่ต่อเนื่องพอจะประเมินได้ จึงไม่เพียงพอให้ตรวจสูตรที่มีเงื่อนไขเป็นลำดับ 69→65 โดยน่าเชื่อถือ

## บางข้อจากรูปที่สาม — คำจำกัดความสมมติที่ไม่ใช่สูตรยืนยัน

| เงื่อนไขตัวอย่าง | ผล | โอกาสพื้นฐานหากเลขสองหลักสุ่มสม่ำเสมอ |
|---|---:|---:|
| เบิ้ลล่าง → ล่างถัดไปมีเลข 8 อยู่ตำแหน่งใดก็ได้ | 143/730 = 19.59% | 19% |
| ล่างหน่วยเป็น 5 → ล่างถัดไปมี 0 | 127/728 = 17.45% | 19% |
| ล่างหลักสิบ 0 → ล่างถัดไปมี 0 | 140/721 = 19.42% | 19% |
| ร้อยบนเป็น 4 → บนถัดไปมี 6 | 205/720 = 28.47% | 27.1% |
| บนเบิ้ลหน้า → ล่างถัดไปมี 7 หรือ 9 | 272/738 = 36.86% | 36% |
| หลักสิบบนและล่างเท่ากัน → ล่างถัดไปมี 3 | 144/730 = 19.73% | 19% |

*หมายเหตุ:* การแปลงข้อความคลุมเครือเป็นเงื่อนไขคณิตศาสตร์เป็นการตีความของผู้ตรวจเท่านั้น ไม่ควรใช้ยืนยันว่าผู้เผยแพร่ใช้กติกาเดียวกัน

| วิธีนับว่าเข้า | เลขนิ่งรายชั่วโมง | เลขสุ่มหนึ่งตัวเมื่อเทียบผล 4 รอบจริง |

Permutation สลับเลขทายภายในวัน 10,000 ครั้ง: ค่า p แบบด้านเดียวบน=0.0160, ล่าง=0.6000, บนหรือล่าง=0.0151 (ผล exploratory, ไม่ใช่ prospective prediction; ไม่ได้ปรับการเลือกหลายโมเดลทั้งหมดในโครงการ)

## ทดสอบความสัมพันธ์ระหว่างรอบกับเลข 2 ตัวล่างถัดไป

ใช้ลำดับผลที่อยู่ติดกันจริง 7,352 คู่; 60% train, 20% validation, 20% test. ตัวแปรที่ทดลอง: เลขล่างเดิมทั้งสองหลัก, เลขหลักหน่วยเดิม, เบิ้ลหรือไม่, เลขหลักหน่วยบนเดิม, ชั่วโมง

- Test: 1,471 คู่
- Baseline เลข 2 ตัว 00–99 แบบ uniform: Log loss 4.60517 (ยิ่งต่ำยิ่งดี)
- Baseline ความถี่จากอดีต: 4.61269
- Model ตามเลขหลักหน่วยล่างก่อนหน้า: 4.61224
- Model ตามเลขล่างก่อนหน้าทั้งสองหลัก: 4.61287
- Model ตามสถานะเบิ้ล: 4.61464
- ไม่พบ model ในชุดที่ทดลองที่ทำ Log Loss ดีกว่าฐาน uniform บนช่วงทดสอบนี้

## ข้อจำกัด

1. ผล 7,469 รอบมาจาก LINE ไม่ใช่ Official API ที่ผู้ตรวจดึงและยืนยันครบทุกแถว
2. Screenshot ทั้งสามไม่มีวันที่เผยแพร่และไม่มีนิยามผลตามที่แม่นยำ/ครบถ้วน จึงต้องยืนยันสูตรกับต้นทาง
3. การโพสต์ LINE อาจมีการแก้ข้อความที่ไฟล์ Export ไม่บอกครบ; เวลาเป็นระดับนาที
4. Backtest ทุกชนิดเป็นการวิจัยย้อนหลัง ยังไม่พิสูจน์ความสามารถทำนายเงินจริง
5. ถ้าเจอรูปแบบจากการค้นกว้างหลายร้อยสูตร ต้องปรับ multiple testing และทดสอบกับข้อมูลในอนาคตที่เก็บหลังล็อกสูตรแล้ว
6. ไม่ควรนำข้อมูลแชตหรือข้อมูลส่วนบุคคลอัปโหลด GitHub สาธารณะโดยไม่จำเป็น
